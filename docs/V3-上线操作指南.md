## 操作步骤（共 5 步）

### 第 1 步：从 V2 合约取出 2000 万 AGG

打开 V2 合约写入页面：
```
https://bscscan.com/address/0xB4089956A0b775638e8F9F2E17deaE35B102c860#writeContract
```

1. 点击 **Connect to Web3**，连接 Owner 钱包
2. 找到 **`emergencyWithdraw`** 函数
3. 填入参数：
   - `token`: `0xCd339aec4797790A8e387eF10035df0000d3a815`
   - `amount`: `20000000000000000000000000` (2000万，18位小数)
4. 点击 **Write**，确认交易

> 执行后 2000 万 AGG 会转入你的 Owner 钱包。

---

### 第 2 步：调整 V2 总奖励

仍在 V2 合约写入页面：
```
https://bscscan.com/address/0xB4089956A0b775638e8F9F2E17deaE35B102c860#writeContract
```

先查询 V2 当前状态（Read 页面）：
```
https://bscscan.com/address/0xB4089956A0b775638e8F9F2E17deaE35B102c860#readContract
```
- 查询 **`totalDistributed`** 的值（记下来，记为 A）
- 查询 **AGG 余额**：在 AGG 代币合约查询 V2 的余额
  ```
  https://bscscan.com/address/0xCd339aec4797790A8e387eF10035df0000d3a815#readContract
  ```
  找到 **`balanceOf`**，输入 `0xB4089956A0b775638e8F9F2E17deaE35B102c860`，记下余额（记为 B）
- 查询 **`totalStaked`** 的值（记为 C）

计算新的 totalRewards = A + B - C

回到 V2 写入页面：
1. 找到 **`setTotalRewards`** 函数
2. 填入参数：
   - `_totalRewards`: 上面计算的值（A + B - C）
3. 点击 **Write**，确认交易

> 这样 V2 前端的进度条和剩余奖励会显示正确。

---

### 第 3 步：设置 V3 推荐比例

打开 V3 合约写入页面：
```
https://bscscan.com/address/0x982D6E5a70034d34837BF7c5DACCee8D188c6913#writeContract
```

1. 点击 **Connect to Web3**，连接 Owner 钱包
2. 找到 **`setReferralRates`** 函数
3. 填入参数：
   - `rates`: `[1000,800,500]`

   > 含义：1代 10%、2代 8%、3代 5%（基数为 10000）
4. 点击 **Write**，确认交易

---

### 第 4 步：设置 V3 总奖励为 2000 万

仍在 V3 合约写入页面：

1. 找到 **`setTotalRewards`** 函数
2. 填入参数：
   - `_totalRewards`: `20000000000000000000000000` (2000万，18位小数)
3. 点击 **Write**，确认交易

---

### 第 5 步：将 AGG 代币充入 V3 合约

打开 AGG 代币合约写入页面：
```
https://bscscan.com/address/0xCd339aec4797790A8e387eF10035df0000d3a815#writeContract
```

1. 点击 **Connect to Web3**，连接 Owner 钱包
2. 找到 **`transfer`** 函数
3. 填入参数：
   - `to`: `0x982D6E5a70034d34837BF7c5DACCee8D188c6913`
   - `amount`: `20000000000000000000000000` (2000万，18位小数)
4. 点击 **Write**，确认交易

---

### 第 6 步：将 V3 合约加入 AGG 白名单（免滑点）

仍在 AGG 代币合约写入页面：
```
https://bscscan.com/address/0xCd339aec4797790A8e387eF10035df0000d3a815#writeContract
```

1. 找到 **`setExcludedFromFee`** 函数
2. 填入参数：
   - `account`: `0x982D6E5a70034d34837BF7c5DACCee8D188c6913`
   - `status`: `true`
3. 点击 **Write**，确认交易

> 不设白名单的话，用户质押/提取时会被扣滑点。
